# Casa da Alcáçova — Concept

Website de demonstração comercial, em página única, para a Casa da Alcáçova em Santarém.

## Executar localmente

```bash
npm install
npm run dev
```

Para criar os ficheiros de produção: `npm run build`.

## Publicar na Vercel

1. Envie apenas esta pasta para um repositório GitHub próprio.
2. Na Vercel, escolha **Add New → Project** e importe esse repositório.
3. Mantenha as definições detetadas: `npm run build` e diretório de saída `dist`.
4. Clique em **Deploy**.

O ficheiro `vercel.json` já está incluído e permite que a aplicação funcione corretamente em qualquer URL da Vercel.
